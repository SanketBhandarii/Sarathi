# Cached notification documents

Every PDF here was downloaded from the official website of the body that
published it. `index.json` records the origin URL, SHA-256 and fetch time for
each one.

These files are committed on purpose. Government websites go down, move pages
and change URLs without notice. Sarathi never states a fact from memory, so it
needs the original document available at all times - including while this
project is being judged.
